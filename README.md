# 龙族圣地巡礼·日本篇

按《龙族Ⅲ 黑月之潮》原文逐章核对的日本圣地巡礼地图：46 个地点、七日行程、实景照片与考据表。

- 在线浏览：https://eoncyrus-lab.github.io/longzu-map/
- 纯静态页面，直接打开 `index.html` 即可，无需构建。
